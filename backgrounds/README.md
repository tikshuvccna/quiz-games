# Backgrounds

Put pictures (`.jpg`, `.png`, `.webp`, `.gif`) or videos (`.mp4`, `.webm`) here: each one appears as a background in
**Room settings → 🎨 רקע** on the host screen, and can be a quiz's default background in the editor.

- Moving backgrounds: an `.mp4` / `.webm` loop plays on the big screen. Phones show a still picture instead, if one
  with the same name exists (`waves.mp4` + `waves.jpg`), to save battery and Wi-Fi.
- Keep videos short (10-30 s loops) and small (under ~20 MB, 1080p or 720p, no sound needed).
- Made with Google Flow: export the image or video and drop it here. The file name (without the number prefix)
  is the name shown in the picker: `03-ocean-dream.mp4` → "ocean dream".
- On weak computers, tick **⚡ מצב חסכוני** in the room settings: animations stop and videos show their still.
